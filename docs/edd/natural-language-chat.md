# 外包尽调报告审核对话

主页面和 `/api/agent/chat`、`/api/agent/chat/stream` 用于审核外包人员撰写的尽调报告，不再直接代写完整客户风险评估。每次请求仍只调用一次回复模型，没有润色、意图路由、联网查询或自动审批。

## 输入

在对话框分别粘贴：

【系统客户资料】：系统字段、业务历史、风险记录和现有等级等。

【外包人员报告】：外包人员自己整理的客户信息和风险评估原文。

【外部查询依据（如有）】：中国执行信息公开网、天眼查等信息的来源、查询日期、事项时间、链接/案号/记录编号或材料摘录，以及主体匹配依据。

同一客户可继续补充，换客户请新建对话。整部分系统资料或外包报告缺失时提示补充，不编造对照结论；两者都有但局部缺失时审核已有内容并说明限制。

## 输出

固定六部分：总体判断、与系统信息不一致之处、遗漏风险点、无依据或来源不明信息、表述与合规性问题、对外包报告的处理建议与等级建议。第二至五部分使用1.、2.编号，每点列出报告表述、依据、问题和修改建议，不逐字段复述OCR，也不代写完整替换稿。

处理建议分为可直接采用、修改后采用、退回重做；关键资料或外部证据未核实不能建议直接采用。采用只是审核建议，实际审批由机构完成。

等级建议区别于前一版的三档洗钱嫌疑标签。升降目标仅使用最高/高/中/低风险客户；高风险场景和其他是标签，不参与升降排序。缺原等级或关键依据时保持现状、不作无依据变更，并说明需核实的信息，不宣称原等级已获认可。

系统资料是比对基准，但外部信息未在系统收录不等于虚假或无风险。审核外部资料的可追溯性、主体匹配、时效及状态；有出处不代表助手实际完成联网核验。区分确定矛盾、风险遗漏、来源待核实和资料不足，避免重复提出同一问题。

提示词位于PromptTemplateConfig，页面说明已同步更新。该对话不经过结构化EDD任务08校验；提示词约束不等于程序证明或自动审批。需要在另机真实模型上检查报告一致性、外部资料处理和漏报误报表现。
