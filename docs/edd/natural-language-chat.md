# 自然语言风险概述

主页面和 `/api/agent/chat`、`/api/agent/chat/stream` 直接生成客户风险概述。输入自然语言客户资料，输出五类信息总结和最后的分析结论。每次请求只调用一次回复模型，不执行润色、意图识别、知识库选择或工具路由。

提示词集中在PromptTemplateConfig，AgentService直接调用ResponseGeneratorNode。首页保留上下文开关，移除了润色与问题件选路实验入口；旧请求中的润色或实验标志不再改变主对话流程。会话历史和流式消息协议继续使用原有实现。

切换客户请新建对话。缺失资料标记待核实，现金不直接决定高风险，无正式评级依据不给出确定建议核心等级。输出为机构审核前建议稿。此快捷对话不经过结构化EDD任务08校验，不宣称程序已核实全文事实。

部署时使用干净构建，避免已删除的图配置和节点class残留。另机启用原有模型配置后直接在首页输入资料；本地测试只用fake模型，不调用真实LLM。

独立的旧问题件实验接口不接入主对话；已有EDD模块所复用的模型隔离与RAG客户端不属于本次删除范围。

本地验证：全量362项测试中360通过、2项真实联网跳过；同步和流式均验证只调用一次模型。首页内联脚本语法检查通过。
